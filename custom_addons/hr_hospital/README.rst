# HR Hospital Module

## Overview

The HR Hospital module is a custom Odoo application designed to manage hospital operations such as patients, doctors, and visits.

## Features

* Patient management
* Doctor management
* Visit scheduling
* Disease classification
* Doctor assignment tracking
* Reports and wizards

## Installation

1. Add the module to your addons path
2. Restart Odoo server
3. Install the module from Apps menu

## Usage

* Create patients and assign doctors
* Schedule visits
* Track visit states (planned, done, canceled)
* Generate reports

## Technical Details

* Built on Odoo 19
* Includes models, views, and business logic
* Covered by automated tests
