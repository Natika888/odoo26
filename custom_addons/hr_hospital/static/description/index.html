HR Hospital Module

The HR Hospital module is a custom Odoo application designed to manage hospital operations efficiently.

Features

  • Patient management
  • Doctor management
  • Visit scheduling and tracking
  • Disease classification
  • Doctor assignment and history
  • Reports and wizards

Key Functionalities

  • Create and manage patients with personal data
  • Assign doctors to patients
  • Track visit status (planned, done, canceled)
  • Prevent assigning interns as doctors for visits
  • Generate reports for doctors and diseases

Technical Details

  • Developed using Odoo 19 framework
  • Includes custom models, views, and business logic
  • Implements access control and security rules
  • Covered by automated tests
